# AGENTS.md

This is a Neovim (`neovim`) configuration project.

The core principal is to keep use of plugins to a minimum AND to use default key mappings where _possible_.
Native features should be preferred over plugins.
Check for duplicate or default key mappings that already exist.

## Neovim Version

Currently installed is 0.12.3. All config should support this version

## Entry Point

`init.lua` is the entry point for neovim custom configuration.

See [KEY_MAPS.md](../KEY_MAPS.md) for full keybinding reference.
